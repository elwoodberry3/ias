06 — CSS Variable Aliases (Functional Tokens)

Swatch CSS Variable Resolved Value Where Used
--primary / --ias-primary #0A2E36 Headers, nav, dark sections, CTA bg
--secondary / --ias-secondary #3F7266 Icons, dividers, secondary labels
--accent / --ias-accent #00E5A3 CTAs, links, active indicators, step markers
--dark / --ias-dark #111827 All body type, strong borders
--light / --ias-light #F9FAFB Page canvas, section fills, code blocks
--white / --ias-white #FFFFFF Card fills, reversed type on dark
--muted / --ias-muted #6B7280 Captions, eyebrows, metadata
--mid / --ias-mid #E5E7EB Hairline borders, dividers, input strokes
